# Simulator Testbed for UAV Swarm Path Planning and Control

Project assigned as part of the internal project evaluations for the **Foundations of Robotics** course, under the guidance of Prof Keshav Ram Kaza and TA Kushagra Srivastava.

---

## 🚀 Project Overview
The objective of this project is to develop a lightweight and scalable simulation testbed dedicated to UAV (Unmanned Aerial Vehicle) swarm path planning and control. The simulator is designed to support complex multi-agent coordination, dynamic constraints, and robust evaluation metrics.

### Key Features & Requirements:
* **Core Capabilities:** Simultaneous path planning, collision avoidance, communication constraints, formation/coordinated control, and mission allocation across multiple UAVs.
* **Environmental Modeling:** Map-based mission specification, realistic UAV dynamics, obstacle maps, and no-fly zones.
* **Algorithmic Approaches:** Multi-Agent Reinforcement Learning (MARL) supporting both **Centralized Training with Decentralized Execution (CTDE)** and fully decentralized policies.
* **Evaluation Metrics:** Path length, area coverage, collision rate, mission completion rate, energy consumption, communication overhead, and scalability with increasing swarm size.
